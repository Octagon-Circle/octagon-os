🚀 Quick Start Tips

  • ⚙️ Open Control Center: octagonos-hello
  • 🎮 Enable Game Mode: octagonos-gamemode on
  • 🐧 Change Kernel: Launch Octagon Hello → Gestor de Kernels (BORE)
  • ⚡ Hyprland: Launch with SUPER + R (Wofi), Terminal with SUPER + Q
  • 📦 Install apps via Discover, Octagon Hello or flatpak install
  • 📦 Install apps via Discover or flatpak install
  • 🔧 System Monitor: btop in terminal
  • 🖥️ GPU Info: vulkaninfo --summary
  • ⚙️ System info: neofetch
  • 🛡️ Firewall: sudo ufw status
